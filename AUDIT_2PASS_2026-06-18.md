### Bug found & fixed this pass (core value)
**Hypothesis engine truncated multi-step PoCs.** The researcher is told to prefer
CHAINED, multi-step hypotheses and `test_plan` is an array, but
`exploitation_agent._test_hypotheses` executed only `plan[0]` — so a chained proof
(e.g. "register low-priv user → hit admin endpoint") only ran step 1, got judged
inconclusive/refuted, and the vuln was MISSED. Fixed: run the full chained plan
(capped at 4 steps), accumulate output, validate against the whole chain. Raises
confirmed-vuln yield — the system's core purpose. Suite **162 passing**.
