# Comprehensive Audit Report: Bugs, Fixes, Upgrades, Features, and Architectural Changes (Lines 8551-11400)

## 1. Bugs and Fixes
- **`get_phase_data` Crash (NoneType)**: `get_phase_data` returned `None`, causing `NoneType has no attribute 'get'` crashes (e.g., in `agents/exploitation_agent.py`). Fixed by ensuring `or {}` fallbacks and proper validation.
- **StateStore Data Validation (`set_phase_data`)**: Field-level schema validation. Stripped `None`-valued fields to prevent downstream crashes. Enforced strict `dict` typing.
- **Silent Exception Handlers**: Over 30-36 instances of bare `except: pass` or `except Exception: pass` (found in `agents/base_agent.py`, `core/orchestrator.py`, `agents/exploitation_agent.py`). Fixed by replacing them with explicit logging (`log.error`) and raising, or explicit fallback behaviors.
- **Agent.run() Return Values Validation**: Phase results were not properly validated. Fixed in `core/orchestrator.py` by rewriting `_execute_phases` and master loop to use `ResultValidator.enforce_boundary()` to handle `None` or non-`PhaseResult` outputs.
- **JSON Parsing Fragility**: Fixed fragile `.split("\`\`\`json")` regex extraction in `agents/persistence_agent.py` (and `tool_manager.py:310, 535`, `exploitation_agent.py:309`) by replacing it with `core.robust_parser.extract_json_list()` and leveraging `FragileParseFixer`.
- **Tool Installation Limit Waste**: Fixed design flaw in `core/tool_installer.py` that caused exponential retries, removing nested loops over strategies and ensuring proper retry/exit logic.
- **`sslscan` URL targeting**: `sslscan` was targeting `http://` URLs instead of bare hosts. Fixed in `base_agent.py` by placing it in the `host_target` category.
- **`gobuster` EOF Death Spiral**: `gobuster` was stuck in a death spiral (all 3 attempts) on connection drops (EOF) due to edge CDNs. Fixed by automatically pivoting/fallback to `ffuf` (different TLS stack) and rotating IPs.
- **`nuclei` Template Degradation**: Timeout escalation system incorrectly downgraded `nuclei` scans to a single hardcoded CVE. Fixed to properly scale down to exposure/misconfig templates (`-tags exposure,misconfig`).
- **`react_payload` AI Attack Vector Ban Spiral**: A timeout from `react_payload` permanently banned all AI attack vectors. Fixed the ban tracking system to correctly extract the primary tool and isolate the specific failed tool.
- **Vercel/Next.js Probes Failing**: All Vercel/Next.js probes failed (6/6). Fixed by implementing early exits for Vercel probes to prevent WAF blocks after consecutive failures (`consecutive_probe_failures >= 2`).
- **PoC Generation "No output"**: Fixed weaponization logic so it no longer attempts to generate PoC scripts for informational findings.
- **Persistence Phase Gate Failed (`NoneType`)**: Validation gates were throwing `NoneType` errors on shell_access fields. Fixed by phase validation enhancements.
- **`pip3` Install Rejected by Allowlist**: Fixed `pip3` installation logic so the system can successfully install required weaponization tools on the VPS.
- **CLI Visual Corruption/Glitchy Logo**: Previous ASCII art was distorted, misaligned, and triggered `UnicodeEncodeError` or string escape syntax warnings on Windows. Fixed by adding `_supports_unicode()` detection, graceful fallback to ASCII safe-sets, raw string wrapping (`r""`), and later redesigned to a robust 6-row tall, 72-char wide boxy block font.
- **Integration Test Failure (`ValueError: Target cannot be empty`)**: `real_integration_test.py` was hardcoded with `target_context=None`. Fixed by dynamically instantiating a proper `TargetContext` from raw URLs (`TargetContext.from_input`).
- **`AttributeError: 'ExploitationAgent' object has no attribute '_find_or_create_wordlist'`**: A stale `.pyc` file in `__pycache__` caused the program to run old code calling a non-existent method. Fixed by clearing all `__pycache__` directories and adding `_find_or_create_wordlist` as an alias to `_resolve_wordlist_path`.
- **Unused `get_config` Import**: Fixed redundant import in `_resolve_wordlist_path` in `base_agent.py`.
- **Repeated Tor Verification (Performance)**: `ensure_tor_ready()` ran 8+ times (once per agent). Fixed by adding a module-level cache in `ip_rotator.py` and sharing the Tor-ready flag via process-level singleton.
- **Repeated `EvasionController` Initialization**: Created 8 times (once per agent). Fixed by sharing `AdaptiveEvasionController` across agents.
- **Repeated `AIBackend` Initialization**: Initialized 3 times, triggering redundant HTTP reachability checks. Fixed by creating a single shared `AIBackend` instance in `main.py`.
- **`nmap -p-` Timeout**: Full port scans generated by AI with a 200s timeout always timed out. Fixed in `recon_agent.py` by adding guards to cap scans at the top 1000 ports and adding `--host-timeout`.
- **`orchestrator.py` Redundant Imports**: `import threading` and `import asyncio` were repeated inside a `while` loop on every phase iteration.
- **`orchestrator.py` Logic Issue with Tor/sshd Checks**: After disk cleanup, `_last_health_check` was set to 0, followed by a check that could skip phases if Tor is down.
- **`orchestrator.py` Exception Handling**: Phase exceptions didn't call `set_phase_status` with `ERROR`, leaving the store with no record of crashes.
- **`ssh_executor.py` Unhandled Timeout**: In `execute_streaming()`, if a channel timeout occurred during `channel.recv_exit_status()`, an unhandled exception was raised.
- **`ssh_executor.py` Logic Error (`AttributeError: 'NoneType'`)**: In `upload()`, `download()`, and `upload_content()`, `self.client` was falsy, `self.connect()` was called but its return value wasn't checked, leading to exceptions on `self.client.open_sftp()`.
- **`state_store.py` Thread Safety / Deadlock**: `close()` acquired `self._lock` (a `threading.Lock`), and a subsequent call from `__del__` caused deadlocks. Suggested fix using `try/finally` without re-locking.
- **`state_store.py` Bare Exception Swallow**: `get_evidence_graph()` swallowed exceptions on `json.loads` without logging (`except Exception: attrs = {}`).
- **`evasion_controller.py` Sleep Duration Bug**: Cooldowns were computed relative to `now` inside a lock, but `time.sleep` ran outside. Overstated sleep durations if lock was held long.
- **`evasion_controller.py` State Loss**: `load_state()` ignored the `hosts` dict from JSON, silently losing data.
- **`ai_backend.py` Dead Code**: `check_all_backends()` had an inner branch that could never be reached.
- **Wordlist Fallbacks & Provisioning**: Fixed `config_paths.py` Wordlist Fallback Check, `agents/base_agent.py` Wordlist Provisioning, and Refactored `agents/exploitation_agent.py` Wordlist Logic. Fix 2.1 Async wordlist retry.
- **Tool Manager False-Success Detection**: Improved in `tools/tool_manager.py`. Fix 2.5: Fix Evidence Context Type Mismatches. Fix 2.6: Comprehensive None Checks.
